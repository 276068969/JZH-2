# 监狱管理平台全栈 Web 应用开发 Prompt

请开发一个「监狱管理平台」全栈 Web 应用，包含后台管理端和前台业务端，支持通过 Docker 一键部署。系统面向监狱管理人员、狱警、医务人员、后勤人员等角色，用于提升监狱内部的信息化管理效率。

## 一、项目目标

构建一个功能完整、界面清晰、安全可靠的监狱管理平台，覆盖服刑人员管理、警员管理、监舍管理、日常巡查、访客会见、医疗记录、事件上报、权限管理等核心业务。

系统需要包含：

- 前台业务端
- 后台管理端
- 用户登录与权限控制
- 数据增删改查
- Docker 部署支持
- 基础测试账号

## 二、核心特点

### 1. 多角色权限管理

系统应支持不同用户角色访问不同功能，例如：

- 超级管理员
- 监狱管理员
- 狱警
- 医务人员
- 后勤人员
- 普通查看人员

不同角色登录后展示不同菜单和操作权限。

### 2. 服刑人员管理

支持对服刑人员进行统一管理，包括：

- 基本信息
- 编号
- 性别
- 年龄
- 所属监区
- 所属监舍
- 刑期信息
- 入狱日期
- 状态管理
- 档案查看

### 3. 警员与工作人员管理

支持管理监狱内部工作人员信息，包括：

- 姓名
- 工号
- 职务
- 所属部门
- 联系方式
- 在职状态
- 角色权限

### 4. 监区与监舍管理

支持管理监狱空间结构：

- 监区管理
- 监舍管理
- 容量设置
- 当前人数统计
- 服刑人员分配
- 监舍状态

### 5. 日常巡查管理

支持狱警记录日常巡查情况：

- 巡查时间
- 巡查区域
- 巡查人员
- 异常情况
- 处理结果
- 巡查记录查询

### 6. 事件上报与处理

支持记录和处理监狱内部事件：

- 事件类型
- 发生时间
- 发生地点
- 涉及人员
- 事件描述
- 处理状态
- 处理结果

### 7. 访客会见管理

支持访客预约和会见记录管理：

- 访客信息
- 被探视人员
- 预约时间
- 会见状态
- 审核状态
- 会见记录

### 8. 医疗管理

支持医务人员维护基础医疗记录：

- 就诊记录
- 病情描述
- 用药记录
- 医生信息
- 复诊状态

### 9. 数据看板

后台首页需要提供基础数据统计，例如：

- 当前在押人数
- 警员数量
- 监舍使用率
- 今日巡查次数
- 待处理事件数量
- 今日访客预约数量

## 三、技术选型

### 前端

建议使用：

- Vue 3
- TypeScript
- Vite
- Element Plus
- Pinia
- Vue Router
- Axios
- ECharts

### 后端

建议使用：

- Java 17
- Spring Boot 3
- Spring Security
- MyBatis Plus
- JWT 认证
- RESTful API

### 数据库

建议使用：

- MySQL 8

### 缓存

可选：

- Redis

### 部署

使用 Docker 进行部署，包含：

- 前端服务
- 后端服务
- MySQL 数据库
- Redis 服务，可选
- docker-compose.yml

## 六、页面要求

前端需要包含：

- 登录页
- 后台布局页
- 左侧菜单栏
- 顶部用户信息栏
- 数据看板页
- 各业务模块列表页
- 新增 / 编辑弹窗或页面
- 详情页
- 搜索和筛选功能
- 分页功能

整体风格应偏政务、严肃、简洁、清晰，适合内部管理系统使用。
